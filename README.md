# 🎓 Campus Hire - Placement & Career Tracking Portal

A comprehensive full-stack MERN application for managing campus placements - combining features of Internshala + LinkedIn + College ERP.

**Status:** 🟢 Active Development | ✅ Backend Foundation Complete

## 🌟 Features

### For Students 👨‍🎓
- ✅ Register and create profile
- ⏳ Upload resume and documents
- ⏳ Browse eligible placement drives
- ⏳ Apply to jobs with one click
- ⏳ Track application status
- ⏳ Get AI-based job recommendations

### For TPO 👔
- ✅ Manage placement drives
- ⏳ Set eligibility criteria
- ⏳ Review and shortlist applications
- ⏳ View analytics

### For Companies 🏢 & Admin 👑
- ✅ Post jobs and manage applications
- ⏳ View global analytics and reports
